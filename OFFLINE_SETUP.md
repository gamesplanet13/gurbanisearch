# Gurbani Searcher — Offline Search & Reading

The Controller is now **offline-first for already-downloaded Sri Guru Granth Sahib Ji (SGGS) Angs**. Its Pages shell, bundled six-pauri Anand Sahib, Sukhmani Sahib, and the concluding Japji Sahib Salok are cached for offline use by `sw.js`.

## Download the SGGS library once

1. Open [Controller](https://gamesplanet13.github.io/gurbanisearch/) **while online**.
2. Find **Offline Gurbani Library** under Search Gurbani.
3. Tap **↓ Save 1430 Angs**. The app fetches each Ang from the [Open Granth](https://github.com/opengranth/open-granth) public corpus (whose Gurmukhi text is derived from [Shabad OS](https://github.com/shabados/shabados)). The progress indicator shows the number saved.
4. Use Pause as needed; tap Save again to resume. Angs already saved are skipped.
5. When **1430/1430** appears, SGGS Ang verses downloaded from BaniDB are available to search locally using IndexedDB. Search works in Airplane Mode after the app's shell has been cached.

The local search includes Gurmukhi first letters, full-word matching and Roman initial-letter/romanized matching from Open Granth's generated Roman transliteration. English meaning is included where the original Open Granth corpus provides DSSK English. Hindi/Punjabi meanings are NOT guaranteed as part of the offline pack.

Opening an offline match:
- When a complete cached Shabad response exists, it opens that Shabad.
- Otherwise, if the source includes a reliable Shabad ID, downloaded Ang lines with the same ID are grouped as the Shabad.
- When no reliable Shabad ID is present, the exact matching **Ang** and verse are shown (not an invented Shabad boundary).

## Limits

- **One-time internet download required for full SGGS coverage.** Simply installing a new APK or visiting the Pages site is **not** a preloaded 1430-Ang database.
- The bulk 1430-Ang download is from **Open Granth** via public GitHub raw files, **not** a bulk copy of BaniDB. It depends on GitHub availability, CORS, rate limits, phone storage quota and reliable network. It is resumable; missing Angs remain unavailable offline until saved.
- The Open Granth corpus is a study aid; it was imported from Shabad OS, and its generated romanization is approximate. Cross-check scripture with authoritative references.
- The downloaded SGGS Ang library is scoped to **1430 Angs**, not every historic or additional text supported by BaniDB.
- Meanings/transliterations are available only if present in downloaded source responses. They are not AI-generated or guaranteed in every language.
- IndexedDB storage is **local to each browser/app profile**; downloading on one device does not transfer the corpus to another. Clearing site/app data deletes it.
- Saved previously opened Shabads can also be reopened offline through their cached response.
- **Projection pairing / live multi-screen sync is not offline yet.** It currently requires PeerJS signaling/network connectivity. Offline search does not imply offline WebRTC pairing.
- A service worker needs an initial online load to install/cache the site shell. APK users may need an updated build for a new version to be seen, but the pages served by GitHub Pages are updated directly.
- Downloading does not alter the Gurbani text. Verify against the canonical Sri Guru Granth Sahib Ji for religious/study accuracy.

## New First-Run Automatic Setup

When the Controller opens on a device without the local SGGS Ang database, it now displays **Download & Install Gurbani Database** and starts downloading automatically. The Controller stays behind a setup screen until all 1430 SGGS Angs are saved, with Retry/Resume after an interruption.

- If `data/offline-packs/manifest.json` lists verified GitHub SGGS bundles, the Controller fetches those compact packs (20 Angs each).
- Until those packs are published, the Controller uses concurrent direct downloads from the Open Granth GitHub corpus.
- Source packs `D` (Dasam Granth), `B` (Bhai Gurdas Vaaran and Kabit Savaiye), `N` (Bhai Nand Lal Ganj Nama) are auto-installed if the public manifest lists them. If absent, the setup explicitly labels them **not yet published**, never falsely marks them complete, and offers access to the already installed SGGS library.
- After setup, the Controller prioritizes locally stored searchable content for faster results. Settings and downloaded scripture remain in that browser/app's IndexedDB unless site data or app data is cleared. Local storage persistence is requested when the browser supports it.
- The Offline Library panel is collapsed by default to leave room for the Gurbani line list. Portrait and landscape layouts have independent scrolling.
- **Offline pairing of multiple devices is not implemented**; PeerJS signaling still requires network availability.

## GitHub Pack Build Status

The source-pack generator scripts are `scripts/build_offline_sggs.py` and `scripts/export_shabados_offline.py`. The GitHub Action at `.github/workflows/build-offline-corpora.yml` generates the manifest and packs. **The existence of scripts or workflow is not proof that the packs have already been generated.** Check `data/offline-packs/manifest.json`: `status: not-built` means source packs are not yet ready on GitHub. Do not claim all sources are available until the manifest shows published files and the download/install has been tested.

Shabad OS texts are imported as original primary Gurmukhi text only. Editorial Hindi/Punjabi/English translations have separate rights and are not assumed redistributable. The Nitnem quick buttons currently include bundled Anand Sahib and Sukhmani Sahib data; the full requested Nitnem collection is not yet independently compiled into one offline package.

## Database section in Controller menu (current behavior)

Open Controller **☰ → bottom → Database · Download / Storage / Version**. Tap the header to expand and tap again to close. It shows SGGS Ang download progress, counts of all saved source packs, database source import, App Version, and **Delete Database**.

- The Controller starts or resumes unfinished local database downloads automatically **while the app/web page is running**, without a blocking full-screen setup; search and projection controls remain usable.
- The source download prioritizes published GitHub packs. Until SGGS bundles have been published it uses Open Granth over the internet as a fallback. Other sources are saved only if their manifest packs exist; unpublished sources are never labeled as downloaded.
- Already downloaded scriptures remain searchable locally. If the requested words are not found in downloaded Angs, online BaniDB search is attempted when internet is available.
- Android/WebView and browsers generally **cannot reliably download while the app is suspended, force-closed or not running**. Downloads resume on next page opening/foregrounding or internet reconnection, not continuously when the process is dead.
- Delete requires confirmation. It removes IndexedDB Angs, source packs, and cached online Shabads **from that device only**. It pauses auto-download until the user presses Download again.
- Deletion of database data does not remove the app, stored device pairing settings, or the static application cache.
- The main source pack manifest at `data/offline-packs/manifest.json` must be populated before a complete all-source offline database can be claimed.
